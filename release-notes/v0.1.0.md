# Kilien Prototype v0.1.0

Initial public prototype of Kilien, an offline-first personal organizer.

## Included

- Today dashboard, task management, calendar, focus timer/stopwatch, and notes.
- Local SQLite storage and manual JSON backup export/import/merge.
- Windows desktop installer.

## Downloads

### Windows PC

Download `Kilien_0.1.0_x64-setup.exe` from the Assets section of this release and follow the Windows installer prompts. The prototype installer is not digitally signed.

### Android

No standalone APK is available for this release. Android packaging and device verification are incomplete.

### iOS

No signed iOS build or TestFlight/App Store distribution is available. Apple build and signing/distribution requirements remain unmet.

## Limitations

Kilien is an early prototype. Data stays on each device; there is no cloud account or synchronization. Habits and routines, AI planning, and advanced analytics are not implemented. Android and iOS builds have not been validated as distributable applications.
